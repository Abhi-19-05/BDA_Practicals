MapReduce splits a massive text document into smaller data chunks.
Mappers process individual chunks to extract every single word found.
Each word generates a structured key-value output formatted as (word, 1).
The framework automatically shuffles and groups identical words together network-wide.
Reducers aggregate these grouped pairs by summing up their total values.
The system delivers a single, consolidated list of final word frequencies.


nano topWordMapper.py

#!/usr/bin/env python

import sys
import re

STOP_WORDS = "the is and a an of to in on for with at by from it this that as are was".split()

for line in sys.stdin:
    words = re.findall(r'[a-zA-Z]+', line.lower())

    for w in words:
        if w not in STOP_WORDS:
            print("%s\t%d" % (w, 1))

#!/usr/bin/env python

import sys

current_word = None
current_count = 0

for line in sys.stdin:
    word, count = line.strip().split('\t')
    count = int(count)

    if current_word == word:
        current_count += count
    else:
        if current_word:
            print("%s\t%d" % (current_word, current_count))

        current_word = word
        current_count = count

if current_word:
    print("%s\t%d" % (current_word, current_count))
